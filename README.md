# Northstar Consulting — Professional business website (demo)

A fictional consulting firm built as a portfolio piece. The layout works for almost any service business: consultancies, agencies, law and accounting firms, IT companies.

**Live demo:** https://gmoo7.github.io/northstar-consulting/

## Pages
- **Home** — hero with value proposition and CTAs, services, about, case studies, testimonials, FAQ, contact band
- **Services** — six services with scope and starting prices, plus a four-step engagement process
- **About** — company story, team, working principles
- **Case studies** — three detailed client projects with measured results
- **Contact** — validated enquiry form, email, phone, office location and hours

## What it demonstrates
- Multi-page static site with shared header, footer and styles
- Fully responsive layout with a mobile menu
- Conversion-focused structure (CTAs on every page)
- Accessible client-side form validation with inline errors
- SEO basics: unique titles and meta descriptions, Open Graph tags, `schema.org` business markup, `sitemap.xml`, `robots.txt`
- Keyboard focus styles, skip link and reduced-motion support

## Stack
Plain HTML, CSS and vanilla JavaScript. No build step, no framework. Open `index.html` or host anywhere.

_All companies, people and figures are fictional._
